# GolangGopherBot

Telegram-бот сообщества GolangGopher для каталога open-source проектов.

## Возможности

- автоматически регистрирует пользователей и обновляет их Telegram-профиль;
- создаёт карточку проекта пошагово через сообщения и inline-кнопки;
- принимает отдельное описание от автора;
- проверяет публичный GitHub-репозиторий и получает описание, язык, звёзды и topics;
- показывает GitHub topics как хештеги и подписывает автора публикации;
- спрашивает, нужны ли проекту контрибьюторы;
- публикует карточку в теме «Ваши проекты» (`message_thread_id=5`);
- показывает каталог Go-проектов с фильтром поиска контрибьюторов;
- позволяет автору обновлять описание, менять репозиторий, повторно получать данные GitHub и закрывать проект;
- даёт администраторам статистику, скрытие проектов и блокировку пользователей;
- хранит данные в SQLite, не требуя отдельного сервера БД.

## Запуск

Требуется Go 1.23+.

```bash
cp .env.example .env
go mod download
go run .
```

Обязательные настройки в `.env`:

```env
BOT_TOKEN=...
PROJECTS_CHAT_ID=-1001234567890
PROJECTS_THREAD_ID=5
ADMIN_IDS=123456789,987654321
```

Для сети языковых групп задайте маршруты JSON-массивом и единый канал:

```env
PROJECT_GROUPS_JSON=[{"language":"Go","chat_id":-1004494598650,"chat_username":"@GolangGopher","thread_id":5},{"language":"Python","chat_id":-1001234567890,"chat_username":"@PythonGroup","thread_id":5}]
PROJECTS_CHANNEL_ID=-1009876543210
PROJECTS_CHANNEL_USERNAME=@AllDevProjects
```

Каждый язык публикуется в своей теме `Ваши проекты`. Общий канал получает
копию карточки со ссылкой на исходное сообщение языковой группы.

`PROJECTS_CHAT_ID` — числовой ID супергруппы. Вместо него можно задать
`PROJECTS_CHAT_USERNAME=@GolangGopher`, но числовой ID надёжнее. Бот должен быть
добавлен в группу и иметь право отправлять сообщения в тему. `GITHUB_TOKEN`
необязателен, но повышает лимит запросов GitHub API.

База по умолчанию создаётся в `data/bot.db`. Путь меняется через
`DATABASE_PATH`.

## Команды пользователя

- `/start` — начало работы;
- `/project` — добавить проект;
- `/projects` — каталог и фильтры;
- `/cancel` — отменить заполнение;
- `/help` — справка.

Незавершённая анкета хранится в памяти до перезапуска бота. Созданные
пользователи и проекты остаются в SQLite.

## Команды администратора

ID администратора должен быть указан в `ADMIN_IDS`. Команды работают в группе:

- `/stats` — статистика;
- `/hideproject ID` — скрыть проект из каталога;
- `/showproject ID` — вернуть проект в каталог;
- `/block TELEGRAM_ID` — заблокировать пользователя в боте;
- `/unblock TELEGRAM_ID` — разблокировать пользователя.

## Проверка

```bash
go test ./...
go vet ./...
```
